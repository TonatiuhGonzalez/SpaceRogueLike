# Git Flow — Unity 2D Project

## Initial Setup (once per machine)

```bash
# Install Git LFS
brew install git-lfs   # macOS
git lfs install

# In project root — track Unity binary files
git lfs track "*.png" "*.jpg" "*.jpeg" "*.psd"
git lfs track "*.wav" "*.mp3" "*.ogg" "*.aif"
git lfs track "*.unity" "*.prefab" "*.asset" "*.mat"
git lfs track "*.fbx" "*.obj" "*.ttf" "*.otf"

git add .gitattributes
git commit -m "chore: configure Git LFS for Unity assets"
```

## Branch Strategy

| Branch | Purpose |
|--------|---------|
| `main` | Stable, playable builds only |
| `develop` | Integration — all features merge here |
| `{type}/{description}` | Feature work |

```bash
# Start a new feature
git checkout develop
git pull origin develop
git checkout -b feature/player-movement
```

---

## Branch Naming

```
feature/{description}     ← new mechanic or system
fix/{description}         ← bug fix
refactor/{description}    ← code cleanup
content/{description}     ← new levels, assets, audio
ui/{description}          ← UI screens or components
```

```bash
# Examples
feature/enemy-spawner
fix/player-jump-double
ui/main-menu-screen
content/level-02
```

## Commit Rules

One atomic logical change per commit.

**Pre-commit checklist:**
- [ ] No `Debug.Log` statements left in production code
- [ ] No commented-out code
- [ ] Scripts compile without errors (check Unity console)
- [ ] Only stage files relevant to this change

**Format:**
```
<type>(<scope>): <Description, first word capitalized, no period>
```

| Type | When |
|------|------|
| `feat` | New mechanic, system, or screen |
| `fix` | Bug fix |
| `refactor` | Code cleanup, no behavior change |
| `content` | New assets, levels, audio |
| `chore` | Project settings, dependencies, LFS |
| `docs` | Skills, CLAUDE.md, GDDs |

```bash
# Examples
feat(player): Add double jump mechanic
fix(enemy): Correct patrol boundary detection
content(audio): Add coin collect and jump SFX
chore(lfs): Add font files to LFS tracking
ui(main-menu): Add settings panel screen
```

## What NOT to Commit

```bash
# Verify before staging
git status

# These should never appear as staged:
Library/        # Unity cache — in .gitignore
Temp/           # Unity temp — in .gitignore
*.csproj        # Generated by Unity — in .gitignore
Debug.Log       # Search before committing:
grep -r "Debug.Log" Assets/Scripts/ --include="*.cs"
```

---

## Merge to Develop

When a feature is complete and tested:

```bash
git checkout develop
git pull origin develop
git merge feature/{description} --no-ff
git push origin develop
```

Use `--no-ff` to preserve the feature branch history in the graph.

---

## Saving Work in Progress

```bash
# Stash uncommitted changes before switching branches
git stash push -m "wip: player movement half done"
git stash pop  # restore when back
```
